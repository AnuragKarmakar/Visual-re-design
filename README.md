# Ceremony-In

Static GitHub Pages build for the AIME Ceremony-In experience.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository.
2. Open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the repository's publishing branch and the `/ (root)` folder.
5. Open the URL GitHub Pages provides.

The site starts at `index.html`. It loads React and ReactDOM from `unpkg.com`, Google Fonts, and the local assets in `assets/`.
